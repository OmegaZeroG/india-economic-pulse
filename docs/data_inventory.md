# Data inventory

Status as of 22 Oct 2026. All sources below are downloaded and load from `data/raw` (run `python src/run_all.py`). Dates in raw file names are the download dates.

| Source | Link | Frequency | First month available | Units | Release lag | File format | Known problems / access status |
|---|---|---|---|---|---|---|---|
| UPI (NPCI) | https://www.npci.org.in/product/upi/product-statistics | monthly | Apr 2017 (loaded) | volume: millions; value: Rs crore | ~1 day after month end (Sep 2026 already out) | Excel via Download button, one file per financial year | Scripts get HTTP 403, so manual download. 114 months (Apr 2017-Sep 2026), no gaps. The Download button failed with a retry error once; the table on the page itself still loaded. Excludes same-account transactions from Aug 2018. Growth in 2018-2020 is explosive adoption, and over 2019-26 it correlates about 0.1 with IIP, so it is left out of the long-sample runs. |
| Fuel (PPAC) | https://ppac.gov.in/consumption/products-wise | monthly | Apr 2000 (loaded, 5 products) | thousand metric tonnes | ~1 week into next month (Sep 2026 out 06.10.2026) | Excel: Historical Report (sheet per FY) + Current Report | Manual download. 318 months, no gaps. Latest months provisional and revised; Aug-Sep 2026 private imports prorated. |
| GST (GST portal) | https://www.gst.gov.in/download/gststatistics | monthly | Jul 2017 (loaded) | Rs crore | ~1st of next month; Aug 2026 is latest | Excel via download icons: state-wise file per FY + one national file (2026-27 only) | Portal firewall blocks scripts, so manual download. 110 months, no gaps. FY2017-18 to FY2019-20 files have no refund data, so net GST exists only from Apr 2020. National file has cess; state files drop cess after FY2024-25, and compensation cess is zero from Apr 2026, so growth uses CGST+SGST+IGST (ex-cess). Jul 2017 (first GST month) is nearly empty. 39 states/UTs; code 99 labelled CBIC in FY2023-24, OIDAR later. Figures are provisional. |
| IIP (MoSPI) | https://api.mospi.gov.in/api/iip/ | monthly | 2023 on base 2022-23 | index, YoY % | ~28th of following month | JSON API | **No key needed (confirmed).** Base years offered: 2022-23, 2011-12, 2004-05, 1993-94. New base 2022-23 has data for years 2023-2026 only, about 40 monthly points. The server needs a legacy-SSL workaround (`OP_LEGACY_SERVER_CONNECT`). Data endpoint: `/api/iip/getIipData` (paginated). Fetched by `src/bronze/fetch_api.py`, parsed by `src/silver/iip.py`: 41 months, Apr 2023 to Aug 2026, no gaps. Latest Aug 2026 = 8.0% YoY. `release_date` is the date we pulled the value, not MoSPI's official release date. |

## IIP base year (decided 23 Oct 2026)
Main series: base 2022-23 (41 months, still updated). Robustness check: base 2011-12 (168 months, ends Mar 2026). The two are never spliced: their growth rates correlate only 0.40 over the 36 overlapping months. See `data_quality_log.md`.
